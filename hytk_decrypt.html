行业调控 SM4解密工具

基于 HytkUtil.java 逻辑实现 · 输入 sysCode / token / method / data 进行解密

参数输入 必填
生成的 SecretKey sysCode + method + yyyyMMdd + token → MD5 → 大写
填写参数后，点击「解密」自动生成
解密结果 SM4/ECB/PKCS5Padding
等待解密...
算法说明
1. 生成 SecretKey：secretKey = MD5(sysCode + method + yyyyMMdd + token).toUpperCase()（取前32个字符）
2. 解密：使用 SM4/ECB/PKCS5Padding 算法，将 secretKey 作为十六进制密钥解码后解密 data（data 为十六进制字符串）
3. 实现参考：HytkUtil.java（BouncyCastle SM4）
